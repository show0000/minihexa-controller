# MiniHexa 컨트롤러

Hiwonder miniHexa 헥사포드 로봇을 Web Bluetooth와 게임패드로 조종하는 Chrome 웹 앱입니다. 3D 시뮬레이터가 내장되어 있어 로봇 없이도 조작을 확인할 수 있습니다.

- 사용 주소: `https://<user>.github.io/<repo>/`

## 요구 사항

- macOS의 Chrome (Web Bluetooth 지원 버전). Monterey의 Intel Mac에서 쓸 수 있는 마지막 버전인 Chrome 150도 지원합니다.
- Bluetooth 게임패드 (macOS에 페어링 가능한 것)

## Chrome에 블루투스 권한 허용하기

1. 시스템 설정 → 개인정보 보호 및 보안 → 블루투스를 엽니다.
2. 목록에서 Google Chrome을 켭니다.
3. Chrome을 완전히 종료한 뒤 다시 실행합니다.

## 게임패드 페어링

1. 시스템 설정 → 블루투스를 엽니다.
2. 패드를 페어링 모드로 두고, 목록에 나타나면 연결합니다.
3. 앱 화면에서 패드의 아무 버튼이나 누르면 인식됩니다.

## 버튼 지정 마법사

- 처음 실행하면 버튼 지정 마법사가 자동으로 열립니다. 안내에 따라 각 동작에 쓸 버튼을 차례로 누르세요.
- 나중에 다시 바꾸려면 "버튼 지정"을 누릅니다.
- 지정한 매핑은 내보내기(export)와 가져오기(import)로 파일에 저장하거나 다른 기기로 옮길 수 있습니다.

## 로봇 연결

1. 로봇의 전원을 켭니다.
2. 앱에서 "로봇 연결"을 누릅니다.
3. 장치 목록에서 `miniHexa`를 선택합니다.
4. 연결되면 배터리와 거리 값이 표시됩니다.

## 비상 정지와 정지 보장

다음 상황에서는 로봇에 정지 명령을 보냅니다.

- 비상 정지 버튼을 누를 때
- 스틱을 놓을 때
- 브라우저 탭을 전환할 때
- 패드 연결이 끊기거나 전원을 끌 때

## 알려진 제약

- 내장 동작(액션)은 블루투스로 중간에 멈출 수 없습니다. 끝날 때까지 기다려야 합니다.
- 회피와 균형 모드는 스틱을 조금이라도 움직이면 종료됩니다.

## 로컬 개발

```
npm install
npm run dev
```

그 밖의 스크립트: `npm test`, `npm run typecheck`, `npm run build`

## vendor/ 디렉터리

`vendor/`에는 Hiwonder 펌웨어와 자료가 들어 있으며, 저장소에 포함되지 않습니다(`.gitignore`). 필요하면 Hiwonder 공식 miniHexa 문서에서 내려받아 `vendor/`에 넣으세요.
