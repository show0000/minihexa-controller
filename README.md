# MiniHexa 컨트롤러

Hiwonder miniHexa 헥사포드 로봇을 Web Bluetooth와 게임패드로 조종하는 Chrome 웹 앱입니다. 3D 시뮬레이터가 내장되어 있어 로봇 없이도 조작을 확인할 수 있습니다.

- 사용 주소: https://show0000.github.io/minihexa-controller/

## 요구 사항

- macOS의 Chrome (Web Bluetooth 지원 버전). Monterey의 Intel Mac에서 쓸 수 있는 마지막 버전인 Chrome 150도 지원합니다.
- Bluetooth 게임패드 (macOS에 페어링 가능한 것)

## Chrome에 블루투스 권한 허용하기

1. 설정 화면을 엽니다.
   - macOS Monterey: 시스템 환경설정 → 보안 및 개인 정보 보호 → 개인 정보 보호 탭 → 왼쪽 목록의 Bluetooth
   - macOS Ventura 이상: 시스템 설정 → 개인정보 보호 및 보안 → Bluetooth
2. 목록에서 Google Chrome을 켭니다. (Monterey에서는 먼저 왼쪽 아래 자물쇠를 눌러 잠금을 풉니다.)
3. Chrome을 완전히 종료한 뒤 다시 실행합니다.

## 게임패드 페어링

1. Bluetooth 설정을 엽니다 (Monterey: 시스템 환경설정 → Bluetooth, Ventura 이상: 시스템 설정 → Bluetooth).
2. 패드를 페어링 모드로 두고, 목록에 나타나면 연결합니다.
3. 앱 화면에서 패드의 아무 버튼이나 누르면 인식됩니다.

## 버튼 지정 마법사

- 처음 실행하면 버튼 지정 마법사가 자동으로 열립니다. 안내에 따라 각 동작에 쓸 버튼을 차례로 누르세요.
- 나중에 다시 바꾸려면 "버튼 지정"을 누릅니다.
- 지정한 매핑은 "매핑 내보내기"와 "매핑 불러오기"로 파일에 저장하거나 다른 기기로 옮길 수 있습니다.
- 동작 버튼 4개에는 동작 번호를 지정합니다. 1~5번은 로봇에 내장된 동작이고, 6~50번은 로봇에 저장해 둔 춤(동작 그룹)입니다.

## 로봇 연결

1. 로봇의 전원을 켭니다.
2. 앱에서 "로봇 연결"을 누릅니다.
3. 장치 목록에서 `miniHexa`를 선택합니다.
4. 연결되면 배터리와 거리 값이 표시됩니다. 연결 직후 앱은 먼저 정지 명령을 보냅니다.
5. "연결 끊기"를 누르면 먼저 정지 명령을 보내고, 로봇이 받았다고 확인된 뒤에 연결을 끊습니다. 0.5초 안에 확인되지 않으면 연결은 끊되 "로봇이 계속 걷고 있을 수 있습니다" 경고를 띄웁니다.

## 비상 정지와 정지 보장

다음 상황에서는 로봇에 정지 명령을 보냅니다.

- 비상 정지 버튼을 누를 때
- 스틱을 놓을 때
- 브라우저 탭을 전환하거나, 다른 앱을 눌러 Chrome 창이 포커스를 잃을 때
- 패드 연결이 끊기거나 전원을 끌 때
- 페이지를 닫거나 새로 고칠 때 (로봇이 걷고 있을 수 있으면 먼저 확인 창이 뜹니다)

비상 정지나 재연결 뒤에는 스틱을 한 번 중앙으로 돌려야 다시 걷습니다. 화면에 "스틱을 중앙으로 돌려 주세요"가 보이면 스틱을 놓으세요.

로봇은 블루투스 연결이 끊겨도 스스로 멈추지 않습니다. 정지 명령이 로봇에 닿았다고 확인되지 않은 채 연결이 끊기면 "로봇이 계속 걷고 있을 수 있습니다" 경고가 뜹니다. 이때는 로봇의 전원을 끄거나 다시 연결하세요(다시 연결하면 정지 명령부터 보냅니다).

## 알려진 제약

- 내장 동작(액션)은 블루투스로 중간에 멈출 수 없습니다. 끝날 때까지 기다려야 합니다. 동작 중에 보낸 명령은 로봇이 버리므로, 앱은 그동안 조종 입력을 잠그고 비상 정지는 동작이 끝나자마자 보냅니다.
- 회피와 균형 모드는 스틱(이동 또는 기울기)을 데드존 밖으로 움직이거나 아무 버튼이나 누르면 종료됩니다.

## 로컬 개발

```
npm install
npm run dev
```

그 밖의 스크립트: `npm test`, `npm run typecheck`, `npm run build`

## vendor/ 디렉터리

`vendor/`에는 Hiwonder 펌웨어와 자료가 들어 있으며, 저장소에 포함되지 않습니다(`.gitignore`). 필요하면 Hiwonder 공식 miniHexa 문서에서 내려받아 `vendor/`에 넣으세요.

## 실기 검증 결과

- [ ] Apple Silicon 맥과 Intel 맥(Chrome 150) 각각에서 BLE 연결, 배터리와 거리 표시
- [ ] 전후좌우 방향이 시뮬레이터와 실기에서 일치하는지 확인 (+y가 앞인지)
- [ ] 스틱을 놓으면 정지, 탭 전환하면 정지, 패드를 끄면 정지, 비상 정지 버튼
- [ ] 내장 동작 1~5의 실제 소요 시간을 측정해 `actions.ts`와 비교 (±500ms 초과 시 수정)
- [ ] 회피와 균형 모드 켜기와 끄기
- [ ] 시뮬레이터 보행 속도(`GAIT.cmPerSecAtMax`)를 실기에 맞게 조정
- [ ] 걷는 중에 맥에서 멀리 떨어뜨려 정지를 보낸 뒤 연결이 끊기게 두기: 로봇이 멈추는지, 멈추지 않았다면 경고가 뜨는지
- [ ] 동작 소요 시간과, 동작 중에 보낸 명령이 버려지는지 (동작이 끝난 뒤 로봇이 그 명령을 실행하지 않는지)
